# Examples

Standalone runnable programs demonstrating `go-messaging`. Each
sub-directory is a self-contained `package main` you can run from the
repo root with `go run ./examples/<name>`.

| Directory | Demonstrates |
|---|---|
| [`request-reply/`](./request-reply) | Canonical `Dispatcher.Request` / `Dispatcher.Reply` flow against the in-memory reference Store. |

For a godoc-rendered runnable example see
[`example_test.go`](../example_test.go) at the repository root.
